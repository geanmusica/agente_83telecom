# SGP

Sistema usado para consultar e registrar informações da operação.

## Funções que serão ensinadas

- Consultar cliente
- Consultar ONU
- Verificar financeiro
- Abrir ordem de serviço
- Agendar visita
- Consultar contrato

## Consulta de ONU coletiva

Usar quando o prédio ou bloco possuir ONU coletiva:

1. Acessar **Relatórios → FTTH → ONU → Consultar**.
2. Aplicar o filtro **5000** e pesquisar.
3. Buscar o condomínio.
4. Localizar o bloco.
5. Verificar o sinal da ONU coletiva.

## Consulta de clientes com fibra individual

Usar quando não existir ONU coletiva no bloco:

1. Acessar **Clientes → Consultar V2 → Serviços de Internet**.
2. Selecionar o condomínio.
3. Preencher o complemento com o bloco.
4. Escolher os status desejados.
5. Abrir cada cliente individualmente, preferencialmente em nova aba.
6. Consultar RSSI e potência óptica.
7. Excluir os status definidos para a consulta.
